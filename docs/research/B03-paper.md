# Cross-platform Material Design for React Native

Paper is a collection of customizable and production-ready components for React Native, following Google’s Material Design guidelines.

[Get started](http://oss.callstack.com/react-native-paper/docs/guides/getting-started) [Try on Snack](https://snack.expo.dev/@react-native-paper/react-native-paper-example_v5)

![](http://oss.callstack.com/react-native-paper/images/home/components.svg)

## Production-ready components

Buttons, inputs, lists, cards, menus, dialogs, navigation, and feedback patterns built for day-to-day product work.

![](http://oss.callstack.com/react-native-paper/images/home/palette.svg)

## Material You theming

Adopt Material 3 color, typography, elevation, and state layers with a theme system designed for real apps.

![](http://oss.callstack.com/react-native-paper/images/home/accessibility.svg)

## Accessible by default

Common interactions, contrast, and state handling are already baked into the component surface instead of left to each screen.

![](http://oss.callstack.com/react-native-paper/images/home/devices.svg)

## Cross-platform parity

Keep design language and component behavior aligned across iOS, Android, and React Native Web from one codebase.

![](http://oss.callstack.com/react-native-paper/images/home/moon.svg)

## Dark mode support

Ship light and dark experiences with the same primitives, including adaptive surfaces and semantic color roles.

![](http://oss.callstack.com/react-native-paper/images/home/versions.svg)

## Migration-friendly docs

Browse stable 5.x, preview 6.x, and legacy static docs from one version selector without splitting the docs experience.
